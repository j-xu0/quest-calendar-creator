# Quest Calendar Creator

> this is my quest exporter. there are many like it, but this one's mine.<sup>[1](https://en.wikipedia.org/wiki/Rifleman%27s_Creed)</sup>

A fully local Svelte app that turns the University of Waterloo Quest List View into an iCalendar (`.ics`) file. Schedule data is parsed in the browser and is never uploaded or stored.

## Features

- Local-only schedule processing with no data sent to a server
- Customizable calendar events
- Separate calendar exports for each class _(planned)_
- More formatting options and quality-of-life improvements _(planned)_

## Development

```sh
bun install
bun run dev
```
